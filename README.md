# ObraFácil — base reduzida

Base de estudo derivada da versão final com Gemini. Mantém estrutura, casa, cards e formulário simples. Ainda não possui fotos dos serviços, chatbot, API Gemini, armazenamento ou exportação dos pedidos. As etapas do roteiro indicam como completar essa base usando a referência fornecida.

Integrantes: Marcelo, Alcimar e Miguel.

Abra index.html no navegador ou use Live Server para testar esta base. Depois de acrescentar o servidor, siga as instruções da referência final.
